# Duaa Shop

Free Android app that finds the cheapest grocery offers near you in the UAE, using store brochures on D4D Online.

- Type items in English or Malayalam (savaala, takkali, veppila…)
- Uses your phone's location to pick your area, or choose an emirate and area
- Shows the cheapest shop for each item and the shops with the most of your items

## Install
Open **Releases → latest** on your Android phone, download `DuaaShop.apk`, and open it. Android asks once to allow installing apps from your browser.

The APK is built automatically by GitHub Actions on every push to `main`.
